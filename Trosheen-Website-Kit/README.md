# Trosheen website kit

*Made to be handed down · Radīts, lai nodotu tālāk*

Everything for the new trosheen.shop in one place. Every file follows **Brand book v3.1**.

## Start here
1. **`index.html`**: open it in a browser to see every asset, with the animations playing.
2. **`IMPLEMENTATION-GUIDE.pdf`** (also `.md`): step-by-step instructions for your developer. Start with section 0, the urgent fixes.
3. **`13-code/example-homepage.html`**: a working homepage built only from this kit (desktop and mobile).
4. **`01-brand-book/trosheen-brand-book-v3.1.pdf`**: the full brand system, the website audit and the motion rules.

## Rules that never change
- Real pieces only, in true colour.
- No buttons inside images.
- The seal is never redrawn or recoloured.
- Gilt and Lichen are never used as text on Linen.
- The name is always **Trosheen**.
